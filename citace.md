# Citace a zdroje

## Zdroje

- CS50's Web Programming with Python and JavaScript, Project 0: Search: <https://cs50.harvard.edu/web/projects/0/search/>
- W3C Markup Validation Service: <https://validator.w3.org/>
- W3C CSS Validation Service: <https://jigsaw.w3.org/css-validator/>
- Portfolio: <https://d3jv1k.github.io/>

## Použité prompty

- „Navrhněte front-end pro Google Search, Google Image Search a Google Advanced Search.“ Zadání projektu obsahovalo požadavky na vyhledávací stránky, pokročilé vyhledávání, tlačítko „I'm Feeling Lucky“ a vzhled podobný Googlu.
- „Vytvořte další stránku v rámci výše uvedeného projektu, která bude obsahovat co největší množství formulářových prvků (input, select, checkbox, radio, textarea, button, ...).“
- „Na všech stránkách projektu budou 2 odkazy na validaci HTML a CSS.“
- „Na všech stránkách projektu bude odkaz na soubor obsahující citace a zdroje, které jste použili při tvorbě projektu.“
- „V rámci google search projektu budete mít i odkaz na své portfolio.“

## Použití AI

HTML a CSS pro tento projekt byly vytvořeny s pomocí AI asistenta na základě výše uvedených promptů.
